# 効果音の命名規則

効果音の名前は、GVM_appで利用者が選ぶときに読む表示名です。
音を使いたい場面から探せるように、次の形式に揃えます。

**用途（音の特徴）**

| 用途の例 | 表示名の例 |
| --- | --- |
| 文字を表示する | テロップ出現（ポン） |
| 正解を伝える | 正解（キラリン） |
| 画面を切り替える | 場面転換（穏やかな風音） |
| 左右の移動を区別する | 横移動（左から右へ） |
| 回数を区別する | 連続表示（2連ポポン） |

## 表記

- 用途を先頭に置き、括弧内に音色・擬音・方向・回数など、選び分けに必要な特徴を入れます。
- 同じ用途は同じ言葉を使います。例：テロップ出現、通知、正解、場面転換、強調。
- 擬音はカタカナ、括弧は全角の「（）」、数量は半角数字に揃えます。例：プニッ、2連、3音。
- 表示名は20文字以内です。短い名前でも区別できるように、不要な形容詞を重ねません。
- GVMなどの接頭辞、管理番号、拡張子は表示名に含めません。同じ表示名は重複させません。
- ファイル名は表示名に拡張子を付けます。例：`テロップ出現（ポン）.wav`。
  GVM_appは拡張子を外した名前を選択画面に表示します。
- 名前はおすすめの用途を表します。合成した小物音・生活音風の音源の説明は、
  [音源一覧](./GVM-編集用効果音.md)で確認できます。

2026-09-05に追加した110種類へ適用しています。以前からある35種類の番号付き素材は、
音源と名前の対応を維持しています。今後追加する効果音には上記形式を使用します。

## 追加・改名するとき

1. `sfx-registry.json`に素材のID、カテゴリ、名前、SHA-256、必要に応じて長さ・サイズを登録します。
   合成パックでは管理番号`presetNumber`と固定シード`seed`も登録します。
2. 新しいファイルを配置します。改名の場合は既存ID・管理番号・シード・音声データを保ち、
   旧ファイルを同じ場所へ残して`aliases`へ登録します。旧URLの利用者も引き続きダウンロードできます。
3. 合成レシピの表示名を`presets.py`と揃え、音源一覧とリンクを更新します。
4. `node scripts/generate-sfx-index.js`と`node --test scripts/generate-sfx-index.test.js`を実行します。
   名前の形式・重複・ID・音声のハッシュ・旧ファイルとの一致・未登録音源を検証します。
5. アプリの選択画面で名前の読みやすさ、検索、試聴、ダウンロードを確認します。

旧ファイルはカタログに重複掲載しません。利用者が既に保存したファイルを移動する処理もありません。
起動中に古い一覧を取得している場合は、アプリの再起動で新しい名前が反映されます。
